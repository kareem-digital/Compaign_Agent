# Exact pins, not ranges: this is public-preview software and ADR-001 requires
# a pinned version.
#
# Both lines are needed. `agent-governance-toolkit` is a meta-package that on
# its own installs almost nothing - the policy engine lives in `-core`, which
# is what provides `agentmesh.governance`. The documented `[full]` extra does
# NOT work: the package never declares `Provides-Extra`, so pip warns, installs
# nothing, and exits 0. Naming the distributions explicitly is the only
# reliable way, and getting this wrong fails at import time in CI.
